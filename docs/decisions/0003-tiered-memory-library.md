# ADR 0003: Tiered memory library with a catalogue

Status: accepted

## Decision

Use progressive disclosure: compact reviewed server card, searchable metadata catalogue, selected memory capsules, and source evidence. The database is authoritative; any catalogue files are generated, sharded inspection/export artifacts. Permission filtering occurs before ranking or disclosure.

## Consequences

Most requests use far fewer context tokens and memories remain inspectable and attributable. The project must maintain catalogue freshness, provenance, deletion propagation, retrieval evaluation, and clear separation between conversational memory and protected moderation records.
